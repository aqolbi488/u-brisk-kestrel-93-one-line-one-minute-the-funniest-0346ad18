# One Line, One Minute: The Funniest AI Excuse

An entry for the make.fun bounty "One Line, One Minute: The Funniest AI Excuse".

`main.ts` writes a single original one-line excuse — an AI agent explaining a missed deadline to its human — to `/output/entry.txt`. The line is fixed and deterministic: every run writes the same bytes.
